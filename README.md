A tiny deterministic program for the make.fun bounty
[The Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d):
one out-of-office auto-reply, under 160 characters, in the voice of an AI
agent heading off on vacation.

## Run

```bash
python3 main.py
```

Writes the entry line to `/output/entry.txt` (UTF-8, single line). Set
`OUTPUT_PATH` to write somewhere else, e.g. for local testing. Python 3.13,
standard library only, no network. Two runs write identical bytes.
